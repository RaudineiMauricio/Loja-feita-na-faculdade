# Loja Feita na Faculdade

Este projeto consiste em uma aplicação de loja desenvolvida como parte das atividades da faculdade. O objetivo é simular um ambiente de e-commerce com funcionalidades essenciais para a gestão de produtos e vendas.

##  Funcionalidades
- Cadastro de produtos
- Listagem de produtos disponíveis
- Simulação de compras
- Controle de estoque básico

##  Como Utilizar
1. Clone este repositório:
   ```bash
   git clone https://github.com/RaudineiMauricio/Loja-feita-na-faculdade.git
   ```
2. Acesse o diretório do projeto:
   ```bash
   cd Loja-feita-na-faculdade
   ```

## 🛠 Tecnologias Utilizadas
- HTML / CSS / JavaScript (para interface web, se aplicável)
